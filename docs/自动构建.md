# 用 tag 触发自动构建

向 `guyu-guyu/activitywatch-plus` 推送一个新的 `v*` tag，就会启动 [Tag Windows](../.github/workflows/tag-windows.yml) 工作流。构建在 GitHub 托管的 Windows Runner 上完成，产物是经典托盘版的 zip 和安装包，并挂到该 tag 的 GitHub Release 上。

在哪台设备上推送都可以。安装包不签名，不需要仓库 Secrets。

## 操作

先拉到包含本工作流的提交，再打一个新 tag 并推送：

```sh
git pull
git tag v0.14.4b1-plus.2
git push origin v0.14.4b1-plus.2
```

tag 名换成尚未使用过的名字。推送完成后，在 [Actions](https://github.com/guyu-guyu/activitywatch-plus/actions/workflows/tag-windows.yml) 里可以看到这次构建。

## 会触发的条件

- 远程是 `guyu-guyu/activitywatch-plus`，不是上游 `ActivityWatch/activitywatch`。
- tag 名以 `v` 开头，例如 `v0.14.4b1-plus.1`。
- tag 指向的提交里已经有 `.github/workflows/tag-windows.yml`。给更早的提交打 tag 不会启动它。
- 这是一个新 tag。已经推送过的 tag 再推一次不会重新构建。只拉取仓库也不会构建。

## 产物

- `activitywatch-<版本>-windows-x86_64.zip`：免安装目录，运行其中的 `aw-qt.exe`。
- `activitywatch-<版本>-windows-x86_64-setup.exe`：安装程序，默认目录是 `C:\Program Files\ActivityWatch`。
- 安装包未签名。Windows 可能会提示未知发布者，选择仍要运行即可。
- 和官方版共用数据目录，并且同一时间只能运行一个。安装或启动前先退出正在运行的官方托盘图标。
